### Secure homelab and operations

A staged infrastructure-modernization project built around discovery, documentation, recoverability, and least privilege:

- inventory and configuration baselines before changes
- segmented services and controlled trust boundaries
- backup, restoration, power-loss, and continuity planning
- monitoring, alerting, and documented operating procedures
- read-only automation first, with approval gates for future actions

This work is documented publicly only as reusable architecture and sanitized examples—not as a map of the live environment.
